# Investigación de curación, UX y controles

## Referencias

- [Batocera — Configure a Controller](https://wiki.batocera.org/configure_a_controller): perfiles de mando y asignación por dispositivo.
- [Batocera — Remapping controls per emulator](https://wiki.batocera.org/remapping_controls_per_emulator): los remaps dependen de emulador/juego.
- [Batocera — Menu tree](https://wiki.batocera.org/menu_tree): favoritos, advertencias BIOS, orden y opciones de UI.
- [Batocera — Write themes for EmulationStation](https://wiki.batocera.org/write_themes_for_emulationstation): la metadata visible depende de vistas soportadas por theme.
- [BYOAC Multi-Player Games](https://wiki.arcadecontrols.com/index.php/Multi-Player_Games): listas comunitarias de multiplayer, útiles para descubrir pero no para certificar.
- [Reddit r/arcade: recomendaciones para fiestas](https://www.reddit.com/r/arcade/comments/1kaveqf/your_top_10_arcade_games_for_parties_with/): señal anecdótica para beats/party.

## Política aplicada

No se usaron listas externas para borrar juegos. Los títulos sugeridos se cruzan con inventario por nombres en `ARCADE_MISSING_MUST_HAVE.md`; un alias no encontrado se presenta como “verificar aliases”, no como ausencia definitiva. El ranking party sólo usa metadata de jugadores, certificados (hoy cero) y señales nominales; no se presenta como popularidad comprobada. La interfaz recomendada reduce la pantalla pública a nombre, cantidad jugadores con etiqueta de metadata y control recomendado; no mostrar core/BIOS.

## Proyectos GitHub revisados

- [Batocera-WebDashboard-Pro](https://github.com/DavidSchuchert/Batocera-WebDashboard-Pro): referencia para panel; amplio alcance y acciones administrativas implican riesgo alto. No instalar.
- [batocera-controlcenter](https://github.com/lbrpdx/batocera-controlcenter): referencia de panel local; revisar origen, permisos/endpoints antes de integrar. No instalar.
- [fliperOS](https://github.com/juniorterin/fliperOS): alternativa de sistema/frontend, no un complemento acotado para esta instalación; no recomendado.

No se descargó ni instaló código, theme o contenido.
